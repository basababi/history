# Blender ассет шугам — «Миний гэр»

Гэрийн диорама ба 12 эд зүйл + түгжээний гэрэгэний дүрсийг **скриптээр**
үүсгэнэ. Гараар хийсэн дүрс бүр өөр өөр харагддаг; скрипт нь нэг
гэрэлтүүлэг, нэг алтан материал, нэг камерын хэв маягийг баталгаажуулна.

| Файл | Үүрэг |
|---|---|
| `nomad_lib.py` | Нийтлэг сан: рендер (Cycles CPU + OIDN, AgX Punchy), материал, гэрэл, камер |
| `ger_diorama.py` | Шөнийн диорама: чулуун тавцан, хан хана, унь, тооно, алтлаг утаа, нээлттэй хаалга |
| `ger_items.py` | 12 эд + гэрэгэ (`--only name1,name2` — зөвхөн заасныг) |
| `postprocess.py` | 192px болгох, диорамын тунгалаг захыг тайрах, шошгоны цэгийг дахин тооцоолох |
| `ger_realtime.py` | **Бодит цагийн 3D гэр** (GLB): жинхэнэ бүтэц (хана/унь дотор, бүрээс гадна), 12 эд уламжлалт байранд, AO оройн өнгөнд |

## Бодит цагийн 3D гэр (`ger_realtime.py`)

```powershell
& $bl --background --factory-startup --python tools/blender/ger_realtime.py -- --out apps/mobile/assets/ger/ger-realtime.glb
```

~40 сек (AO шатаах орно). Гаралт: ~134 мянган гурвалжин, ~5 MB, текстургүй.

**Гэрээ — апп ↔ GLB зангилааны нэр** (`src/ger3d/`-тэй яг таарах ёстой;
`tests/ger3d.test.ts` энэ гэрээг шалгана):

| Зангилаа | Утга |
|---|---|
| `ger_shell` | байнгын бүх геометр, материалаар хуваагдсан |
| `stove` | төмөр зуух — «Гал голомт» байрлуулахад нуугдана |
| `default_table` | хойморын ширээ — «Модон авдар» байрлуулахад нуугдана |
| `item_<key>` | байрлуулж болох эд; `key` = `src/ger3d/itemKeys.ts` |
| `anchor_<zone>` | 3D шошго: khoimor, baruun, zuun, golomt, toono, bosgo |
| `cam_*`, `orbit_target`, `light_*`, `smoke_origin` | камер, гэрэл, утааны цэг |

Эдийн байрлал (уламжлалт зохион байгуулалт, хаалга өмнө зүгт):
ширдэг — гал голомт ба хойморын хооронд · авдар/тогоо — хоймор · зул —
хойморын ширээн дээр · морин хуур/ятга — баруун (эрэгтэй) тал · хивс/хөшиг —
зүүн (эмэгтэй) тал · Соёмбо — тоононоос унжина · гал голомт — төвд (зуухыг орлоно).

**three.js 0.162.0-д түгжсэн.** expo-gl нь зарим төхөөрөмж/эмулятор дээр
WebGL1 өгдөг, мөн түүний WebGL2 класс WebGL1-ээс удамшдаг тул three r163+
«WebGL 1 is not supported» гэж унана. Дэлгэрэнгүйг `src/ger3d/GerEngine.ts`.

## Дахин үүсгэх

Шаардлага: Blender 5.1+, Python 3 + Pillow.

```powershell
$bl = "C:\Program Files\Blender Foundation\Blender 5.1\blender.exe"
& $bl --background --factory-startup --python tools/blender/ger_diorama.py -- --out out/ger-diorama.png --rx 1080 --ry 996 --samples 128
& $bl --background --factory-startup --python tools/blender/ger_items.py -- --outdir out/icons --res 384 --samples 96
python tools/blender/postprocess.py out/icons out/ger-diorama.png out/ger-diorama.anchors.json
```

`postprocess.py`-ийн хэвлэсэн `GER_DIORAMA_RATIO` ба `GER_ANCHORS`-ийг
`apps/mobile/src/components/GerArt.tsx` руу хуулна (камер эсвэл харьцаа
өөрчлөгдсөн үед л).

Хугацаа (i7-1355U, зөвхөн CPU): диорама ~3 мин, 13 эд ~4 мин.

## Анхаарах

- **`film_transparent`** — JPEG биш PNG (альфа). Хуучин `yurt-3d.jpg`-ийн
  «цагаан дөрвөлжин» асуудлын үндсэн шалтгаан нь альфа суваггүй байсан.
- **AgX Punchy** — энгийн AgX улаан → ягаан, хөх → цайвар цэнхэр болгож
  «пастел» харагдуулж байв.
- **Хан ханын хаалганы нүхийг boolean-аар гаргахгүй** — огтлолцсон тууз
  тул EXACT solver торыг бүхэлд нь устгадаг. Сегментийг алгасна.
- **Хүннүгийн тогооны хөл богино** — өндөр бол цомын аяга шиг харагдана.
- **Гэрэгэ урт, нарийн (≈1:2.4)** — өргөн бол дугуй оройтой хаалга шиг.
- **Шалны сүүдэр анхдагчаар унтраалттай** — апп түгжээтэй эдийг `tintColor`-оор
  сүүдэр-дүрс болгодог тул бүдэг сүүдэр ч будагдаж ард нь «хайрцаг» үүсгэдэг.
  Маркетингийн зурагт `--floor-shadow 1`.
