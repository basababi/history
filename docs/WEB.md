# Эртний Өв · Өдрийн тав — вэб бүтээгдэхүүн

> 2026-10 · Зорилтот хэрэглэгч: **18–25 нас**. Эхлээд **вэб**, дараа нь ижил кодоос апп.

## Бүтээгдэхүүн нэг өгүүлбэрээр

Өдөр бүр **бүх хүнд ижил 5 асуулт** (Монголын түүх, домог, зүйр үг). Дуусгаад
**линкээр найзаа сорино** — найз нь бүртгэл, суулгалтгүйгээр шууд тоглож, хэн нь
түрүүлснийг харна. Найзын **бүлэгт** долоо хоног бүр чансаа.

| Үйлдэл | Хаана |
|---|---|
| Өнөөдрийн тав тоглох | `/` → «Эхлэх» → `/play/2026-10-19` |
| Дүн, тайлбар, хуваалцах | `/result/2026-10-19` |
| Найзын сорилт (Messenger-ээр ирнэ) | `/c/ABCD2345` |
| Найзын бүлэг | `/groups`, `/groups/12` |
| Бүлгийн урилга | `/g/ABC234` |
| Нэр, цол, сэргээх код | `/me` |

## Шударга байдлын дүрэм (сервер хэрэгжүүлнэ)

- Зөв хариулт хариулсны **дараа** л ирнэ; сонголтын дараалал өдөр + асуулт бүрд холилдоно.
- Асуулт **нэг нэгээр** нээгдэнэ, хугацааг **сервер** хэмжинэ (асуулт бүрт 20 сек).
  Тайлбар унших хугацаа тооцогдохгүй. Хуудас сэргээхэд таймер шинээр эхлэхгүй.
- Нэг өдрийг **нэг л** удаа (ӨС-ийн `UNIQUE(user_id, day_key)`).
- Сорилтын линк **спойлергүй** — зөвхөн дүн, асуулт хэзээ ч илчлэгдэхгүй.
- Цуврал зөвхөн тухайн өдрийн тавыг тэр өдөрт нь тоглоход тооцогдоно.

## Нэвтрэлт

| | Вэб | Апп (2-р шат) |
|---|---|---|
| Session | `HttpOnly; Secure; SameSite=Lax` cookie (`__Host-ov_session`) | Bearer токен (AsyncStorage) |
| Эхлэл | `POST /api/auth/session`: cookie → сэргээх код → шинэ зочин | ижил |
| Хугацаа | 90 хоног, гулсах: 30 хоногоос хойш орвол шинэ 90 хоног | ижил |
| CSRF | `SameSite=Lax` + `Sec-Fetch-Site`/`Origin` шалгалт (бичих хүсэлтэд) | хамаарахгүй |

**Яагаад localStorage биш вэ?** Safari 7 хоног ороогүй сайтын скриптээр бичсэн
өгөгдлийг устгадаг. Тэгвэл зочин цувралаа алдана. Сервер тавьсан HttpOnly cookie-д
энэ хязгаар хамаарахгүй, XSS ч уншиж чадахгүй. localStorage-д зөвхөн сэргээх
код үлдэнэ. Түүнийг мартсан ч cookie-оор нэвтэрсэн хэвээр байх тул «Би» → «Шинэ код
авах» дарна (`POST /api/me/recovery`, хуучин код хүчингүй болно).

## Архитектур

```
apps/mobile   Expo (React Native Web) — вэб ба апп нэг код
   └─ npm run build:web  →  apps/api/public/   (SPA экспорт)
apps/api      Next.js — НЭГ ДОМЭЙН:
   /api/*        API
   /c/:code      сорилтын линк (OG мета-тай index.html)
   /g/:code      бүлгийн урилга
   /api/og/*     Messenger/Instagram-ийн карт (PNG, Montserrat фонт)
   бусад         SPA (index.html)
packages/core       цэвэр логик (багц сонголт, оноо, тулаан, цол, монгол тийн ялгал)
packages/contracts  zod гэрээ
packages/db         Drizzle схем + migration
```

## Локалаар ажиллуулах

```bash
npm install
npm run db:dev          # терминал 1 — локал Postgres (PGlite)
npm run dev:api         # терминал 2 — API :3001
npm run dev:web         # терминал 3 — вэб :8081 (API-г Metro проксигоор)
```

Production горимоор (нэг домэйн) турших:

```bash
npm run build                                  # вэб экспорт + next build
cd apps/api && npx next start -p 3001          # http://localhost:3001
```

> ⚠ PGlite нэг зэрэг **нэг** холболт авдаг. API-г хүчээр зогсоосны дараа ӨС
> «ECONNRESET» өгвөл `npm run dev:stop` хийгээд хоёуланг нь дахин асаа.

## Байршуулах (Vercel)

1. Vercel төсөл — **Root Directory:** `apps/api`, **Build Command:** `cd ../.. && npm run build`
2. Орчны хувьсагч:

| Нэр | Утга |
|---|---|
| `DATABASE_URL` | Neon Postgres |
| `SESSION_SECRET` | ≥32 тэмдэгт санамсаргүй утга (`openssl rand -base64 48`). Богино бол сервер хүсэлт хүлээж авахгүй. |
| `PUBLIC_WEB_URL` | `https://ertniiov.mn` — OG зургийн абсолют хаяг |
| `DAILY_LAUNCH_DAY` | эхний өдөр (#1), ж нь `2026-11-01` |
| `REDIS_URL` | Upstash — хурдны хязгаар (байхгүй бол санах ойд) |

3. Migration: `npm run db:migrate` үүсгэсэн SQL-ийг Neon дээр ажиллуулна (`packages/db/drizzle`).
4. Байршуулсны дараа: `GET /api/health` → `{ ok: true }` (≥5 нийтлэгдсэн асуулт).
5. Messenger-ийн карт шалгах: <https://developers.facebook.com/tools/debug/> дээр `…/c/КОД`.

## Агуулга нэмэх

`packages/db/src/seed/questions.ts`-д асуулт бүр:

- `format`: `classic` · `myth_or_fact` («Үнэн үү, домог уу?» — сонголт «Үнэн», «Домог», холихгүй) ·
  `proverb` (зүйр үгийг өнөөгийн нөхцөлд) · `what_if` («Чи тэр үед байсан бол?»)
- `sourceRef` **заавал**, `status: 'draft'` → түүхч шалгасны дараа `published`.
- Зөв хариултыг аль ч байрлалд бичсэн байж болно — сервер өдөр бүр холино.

**Тоо:** өдөрт 5 шинэ асуулт → сард **~150**. Одоо 21 — сан бага үед систем хамгийн
эрт ашигласан асуултыг давтана (тасрахгүй), гэхдээ хэрэглэгч анзаарна.
