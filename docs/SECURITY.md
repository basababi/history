# Аюулгүй байдлын бодлого

## Хамаарлын эмзэг байдал

| Түвшин | Бодлого |
|---|---|
| **critical** | CI унана. Хэзээ ч `main`-д орохгүй. |
| **high** — production серверт (`apps/api`) | Илэрсэн өдөр засна. |
| **high** — зөвхөн build хэрэгсэлд | Засвар гарвал Dependabot PR нээнэ. Засваргүй бол доор бүртгэнэ. |

Dependabot долоо хоног бүрийн Даваа гарагт PR нээнэ. Expo, React Native-ийг
`npx expo install --fix`-ээр гараар шинэчилнэ. Хувилбарууд нь хоорондоо
уялдаатай тул тусад нь өсгөвөл эвдэрдэг.

## Нууц утга

- `.env` хэзээ ч commit хийгдэхгүй (`.gitignore`). Шинэ хувьсагчийг `.env.example`-д **утгагүйгээр** нэмнэ.
- Production-д `SESSION_SECRET` заавал: дор хаяж 32 байт санамсаргүй утга (`openssl rand -base64 48`).
- Нууц утга алдагдвал **солино**. Commit-оос устгах нь хангалтгүй, учир нь git түүх үүнийг хадгалсаар байдаг.
