# Бодит төхөөрөмж дээрх шалгалт

> Хэнд: гаргахаас өмнө утсаар шалгах хүн (хөгжүүлэгч эсвэл туслах найз).
> Хугацаа: ~45 минут. Staging хаяг: [DEPLOY.md](DEPLOY.md)-ийн 3-р алхам.

Автомат тест (559+) болон headless Chrome-ийн e2e логикийг шалгадаг. Харин
**Safari, Messenger доторх хөтөч, бодит хуваалцах цонх**-ыг зөвхөн бодит
утас дээр шалгаж болно. Мөр бүрийг ✓ / ✗ болон дэлгэцийн зургаар тэмдэглэнэ.

## Төхөөрөмжүүд

| # | Төхөөрөмж | Хөтөч | Хамгийн чухал нь |
|---|---|---|---|
| A | iPhone (iOS 17+) | Safari | ховил, гар, хуваалцах, нүүр дэлгэц |
| B | iPhone эсвэл Android | **Messenger доторх хөтөч** | 18–25 насны ихэнх энүүгээр орж ирнэ |
| C | iPhone эсвэл Android | Instagram доторх хөтөч | story-оос ирэх урсгал |
| D | Android | Chrome | суулгах санал, хуваалцах |
| E | Компьютер | Chrome / Edge | гар (1–4, Enter) |

## A. iPhone Safari

| # | Үйлдэл | Хүлээгдэх үр дүн | ✓/✗ |
|---|---|---|---|
| A1 | Staging хаягийг нээнэ | 3 секундэд «Өдрийн тав» гарна. Бүртгэл асуухгүй. | |
| A2 | Дэлгэцийн дээд, доод хэсэг | Гарчиг ховилын (notch) доор орохгүй, табын мөр home-индикаторын доор орохгүй. | |
| A3 | «Эхлэх» → 5 асуулт | Таймер явна. Хариулт, тайлбар, эх сурвалж харагдана. Товч хуруунд таарна. | |
| A4 | Дүн → нэр бичих | **Гар нэр бичих талбар, «Хадгалах» товчийг таглахгүй.** | |
| A5 | «Story зураг» | iOS-ийн хуваалцах цонхонд **зураг** гарна. Instagram сонгоход story руу орно. | |
| A6 | «Линк» | Хуваалцах цонх эсвэл «хуулагдлаа» мэдэгдэл гарна. | |
| A7 | Хуваалцах → «Нүүр дэлгэцэд нэмэх» | Дүрс, нэр «Эртний Өв». Дүрсээр нээхэд Safari-ийн мөргүй бүтэн дэлгэцээр нээгдэнэ. | |
| A8 | Safari-г бүрэн хаагаад маргааш нээх | **Ижил хэрэглэгч**: нэр, цуврал хэвээр байна (cookie). | |
| A9 | «Би» → сэргээх код → «Хуулах» | Код хуулагдана. | |
| A10 | Хувийн (Private) цонх | Шинэ зочноор тоглоно, алдаа гарахгүй. | |

## B. Messenger

| # | Үйлдэл | Хүлээгдэх үр дүн | ✓/✗ |
|---|---|---|---|
| B1 | [Sharing Debugger](https://developers.facebook.com/tools/debug/) → `/c/КОД` | `og:image` 1200×630 харагдана, гарчигт оноо байна. Зөвхөн `fb:app_id` анхааруулга байж болно. | |
| B2 | Линкийг Messenger чатад илгээнэ | **Карт**: зураг + «… чамайг сорьж байна». | |
| B3 | Хүлээн авагч карт дээр дарна | Messenger доторх хөтөчөөр нээгдэнэ. Бүртгэлгүйгээр **яг тэр 5 асуулт** гарна. | |
| B4 | Тоглоод дуусгана | Тулааны дүн: «Чи хожлоо / Тэнцлээ». | |
| B5 | Дотор хөтөч дээр «Хуваалцах» | Хуваалцах цонх гарна, эсвэл **«Линк хуулагдлаа»** гарна (энэ хөтөч ихэвчлэн хуваалцах API-гүй). | |
| B6 | `/g/КОД` бүлгийн урилгыг Messenger группэд илгээнэ | Бүлгийн нэр, гишүүдийн тоотой карт гарна. | |

> ⚠ Messenger, Instagram-ын доторх хөтөч нь Safari/Chrome-оос **тусдаа cookie**
> сантай. Дотор тоглосон хүн Safari-аар нээвэл шинэ зочин болно. Энэ нь хөтчийн
> хязгаарлалт. Тэр үед «Би» → сэргээх кодоор нэг бүртгэлдээ орно.
