# Агуулгын урсгал — асуулт бичихээс нийтлэх хүртэл

> Хэнд: асуулт бичигч оюутан, хянагч түүхч, нийтлэгч хөгжүүлэгч.
> Зорилт: **сард ~150 асуулт**, шинэ асуултын нөөц **үргэлж ≥30 хоног**.

Quiz апп кодоос болж биш, агуулга дуусаад үхдэг. Өдөр бүр бүх хүнд ижил 5 асуулт
гардаг тул нэг алдаатай асуулт мянган хүний дэлгэцийн зургаар тарна. Тиймээс
асуулт бүр **эх сурвалжтай**, **түүхчээр хянагдсан** байж байж нийтлэгдэнэ.

## Урсгал

```
Google Sheets (бичих, хянах)
  → Файл → Татах → CSV
  → content/questions.csv-г солиод commit / PR
  → CI: npm run content:check (алдаатай бол merge хийгдэхгүй)
  → npm run content:import -- --dry-run   (production ӨС, юу өөрчлөгдөхийг харна)
  → npm run content:import
  → npm run content:runway                (нөөц хэдэн өдөр үлдсэн)
```

`content/questions.csv` бол **цорын ганц эх сурвалж**. ӨС-д гараар засвар
хийхгүй. Хийвэл дараагийн импорт түүнийг дарж бичнэ. Git түүх нь хэн, хэзээ,
юуг өөрчилснийг хадгалдаг аудит болно.

## Баганууд

| Багана | Утга | Жишээ |
|---|---|---|
| `key` | Тогтвортой түлхүүр. **Хэзээ ч бүү солиорой.** Латин, тоо, зураас. | `Q-0042` |
| `format` | `classic` · `myth_or_fact` · `proverb` · `what_if` (эсвэл монголоор: сонгодог · үнэн/домог · зүйр үг · хэрэв) | `classic` |
| `era` | Эриний түлхүүр эсвэл бүтэн нэр (доорх хүснэгт) | `mongol` |
| `difficulty` | `easy` · `medium` · `hard` (амархан · дунд · хүнд) | `medium` |
| `question` | 10–280 тэмдэгт | Их Засгийг хэн баталсан бэ? |
| `option_a`…`option_d` | 4 сонголт, тус бүр ≤90 тэмдэгт. Зөв хариултыг **аль ч байрлалд** бичиж болно, учир нь сервер өдөр бүр холино. | |
| `correct` | `A` `B` `C` `D` (эсвэл кирилл `А Б В Г`) | `A` |
| `explanation` | 20–600 тэмдэгт. Яагаад зөв бэ, мөн **нэг шинэ баримт**. | |
| `source` | **Заавал.** Ном, боть, хуудас, баримтын нэр. | Монголын нууц товчоо, §202 |
| `status` | `draft` (ноорог) · `reviewed` (хянасан) · `published` (нийтэлсэн) | |
| `reviewer` | Нийтлэхийг зөвшөөрсөн түүхчийн нэр. `published` бол **заавал**. | Д. Батболд |

Баганын дараалал хамаагүй. Нэмэлт багана (ж нь «тэмдэглэл») байж болно,
импорт түүнийг үл тооцно.

## Дөрвөн хэлбэр

| Хэлбэр | Юу вэ | Жишээ |
|---|---|---|
| **classic** | 4 сонголттой мэдлэгийн асуулт | «Хархорумыг аль хааны үед нийслэл болгосон бэ?» |
| **myth_or_fact** | «Үнэн үү, домог уу?» — өгүүлбэр. Сонголтыг **хоосон** орхино: автоматаар «Үнэн», «Домог» болно (холихгүй). `correct` = `A` (үнэн) эсвэл `B` (домог). | «Чингис хааны булш олдсон.» → B |
| **proverb** | Зүйр үгийг өнөөгийн нөхцөлд | «"Ам алдвал барьж болдоггүй" — аль нөхцөлд хамгийн тохирох вэ?» |
| **what_if** | «Чи тэр үед байсан бол?» — шийдвэр, үр дагавар | «1921 онд Хиагтад байсан бол юуг хамгийн түрүүнд хийх байсан бэ?» |

18–25 насныханд он тоо цээжлэх биш, **«өө, тийм юм уу!»** гэх мэдрэмж хэрэгтэй. Хэлбэрүүдийг ойролцоо тэнцүү холино.

## Чанарын шалгуур (хянагч түүхчид)

1. **Нэг асуулт = нэг баримт.** «Ба», «мөн» гэсэн давхар асуулт биш.
2. **Буруу сонголтууд итгэл төрүүлэхүйц**, ижил төрлийн, **ижил урттай**. Зөв хариулт хамгийн урт байвал тоглогч уншилгүй таана. Шалгагч үүнийг анхааруулна.
3. **«Дээрх бүгд», «аль нь ч биш» хориотой.** Сонголт холигддог тул ажиллахгүй. Шалгагч хаана.
4. **Эх сурвалж тодорхой**: «Монголын түүх» биш, харин «Монгол улсын түүх, II боть, 145-р тал».
5. **Маргаантай** (эрдэмтдийн дунд санал зөрдөг) баримтыг **асуухгүй**, эсвэл тайлбарт «нэг хувилбараар» гэж тодорхой бичнэ.
6. **Тайлбар нь нэмэлт мэдлэг** өгнө: зөв хариултыг давтахгүй, нэг шинэ баримт нэмнэ.
7. **Дөрвөн нүдний зарчим**: бичсэн хүн өөрөө хянагч болж болохгүй.

## Тоо ба хэмнэл

Өдөр бүр **2 амархан + 2 дунд + 1 хүнд**. Сард:

| | Сард | Долоо хоногт |
|---|---|---|
| амархан | 60 | 14 |
| дунд | 60 | 14 |
| хүнд | 30 | 7 |
| **нийт** | **150** | **35** |

- **Гаргахаас өмнө** дор хаяж 30 хоногийн нийтлэгдсэн асуулт бэлэн байна.
- Долоо хоног бүр `npm run content:runway` ажиллуулна. 30 хоногоос доош бол тушаал `exit 2` буцаана (cron-д ашиглаж болно).
- Нөөц дуусвал систем зогсохгүй, хамгийн эрт ашигласан асуултыг давтана. Гэхдээ тогтмол тоглогч үүнийг анзаарна.

## Алдаа засах

| Нөхцөл | Хийх |
|---|---|
| Үсгийн алдаа, тайлбар, эх сурвалж | CSV-д засаад импортлоно. Аль хэдийн гарсан асуултад ч болно. |
| **Хараахан гараагүй** асуултын хариулт буруу | CSV-д засна. |
| **Өдрийн тавд гарсан** асуултын хариулт буруу | Импорт **татгалзана**, учир нь тоглогчдын дүн, найзын тулаан тэр хариултаар бодогдсон. Асуултыг `draft` болгоод **шинэ түлхүүрээр** зөвийг нэмнэ. Түүхч алдааг баталсан тохиолдолд л: `npm run content:import -- --allow-answer-change`. |
| Асуултыг нийтлэлээс хасах | `status`-ийг `draft` болгоно. **Мөрийг устгахгүй.** CSV-ээс хасагдсан асуулт ӨС-д хэвээр үлдэнэ (импорт анхааруулна). |

Импорт **бүгд эсвэл юу ч үгүй**: нэг асуулт татгалзагдвал юу ч бичигдэхгүй.

Тоглогч «алдаа байна уу?» товчоор мэдээлсэн асуултууд `content_reviews` хүснэгтэд
хуримтлагдана. Долоо хоног бүр хянана.

## Тушаалууд

```bash
npm run content:check                       # content/questions.csv-г шалгана (ӨС хэрэггүй)
npm run content:check -- path/to/file.csv   # өөр файл
npm run content:import -- --dry-run         # DATABASE_URL дээр юу өөрчлөгдөхийг
npm run content:import                      # оруулна (нэг транзакц)
npm run content:runway                      # нөөц, хэлбэр, эрин, хянагдаагүй тоо
```

Production ӨС руу: `DATABASE_URL=<Neon> npm run content:import`.
